# EthioNewsHub-inspired Tribune Bangla design

Reference: [EthiopianNewsHub](https://github.com/haile12michael12/EthiopianNewsHub), a Laravel news portal. This is an original visual and information-architecture adaptation for Tribune Bangla. It does not copy the reference project's Laravel source and does not migrate Tribune Bangla's backend to Laravel.

## Adapted structure
- Latest-news strip and lead editorial content
- Category-led homepage modules, with four latest stories per active category
- Ten latest and ten popular stories in the sidebar (existing Tribune implementation)
- Advertisement positions and responsive desktop/tablet/mobile layouts
- Updated article reading surface, cards, navigation and typography

## Preserved
- Tribune Bangla Bengali identity, Hind Siliguri, article URLs and metadata
- Existing Supabase data, authentication, reader/reporter/editor/admin workflows
- Pending editorial approval for RSS/auto-news
- Existing production branch and live domain; changes are staged through the integration pull request
