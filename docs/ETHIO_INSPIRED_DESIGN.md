# EthioNewsHub-inspired Tribune Bangla design

Reference: [EthiopianNewsHub](https://github.com/haile12michael12/EthiopianNewsHub), a Laravel news portal. This is an original design adaptation using Tribune Bangla's existing markup and data workflows; it is not a Laravel migration and does not copy the reference project's Laravel source.

- Retains Tribune Bangla branding, Hind Siliguri, Supabase, article routes, SEO, authentication, editorial roles and RSS approval.
- Adapts the reference homepage structure: latest/breaking strip, lead story, category-led modules and ad placements.
- Shows four latest stories per active category.
- Sidebar: ten latest stories and five popular stories.
- Uses an isolated stylesheet and a dedicated feature branch.
- Production branch/domain and database policies are unchanged.
